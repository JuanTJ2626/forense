Metodología

El enfriamiento de un cuerpo se modela con la Ley de Enfriamiento de Newton, una ecuación diferencial de primer orden que relaciona la temperatura T con el tiempo t:

dT/dt = −k · (T − T_amb)

Solución exacta

Esta ecuación tiene solución analítica cerrada, usada aquí como referencia para medir el error de los métodos numéricos:

T(t) = T_amb + (T₀ − T_amb) · e^(−k·t)

Método de Euler

Aproxima la curva avanzando en pasos de tamaño h, usando la pendiente evaluada solo al inicio del intervalo:

T_(n+1) = T_n + h · f(t_n, T_n)

Método de Euler mejorado (Heun)

Corrige el resultado promediando la pendiente inicial con una pendiente estimada al final del intervalo (predictor–corrector), reduciendo el error de truncamiento:

T*_(n+1) = T_n + h · f(t_n, T_n)  (predictor)
T_(n+1) = T_n + h/2 · [ f(t_n, T_n) + f(t_(n+1), T*_(n+1)) ]  (corrector)

Estimación de la hora de muerte

Se simula la curva hacia adelante desde T₀ (temperatura corporal normal) y se ubica el instante en que cada método cruza la temperatura medida T_m. Ese tiempo transcurrido se resta de la hora del hallazgo. La solución exacta permite calcular el mismo cruce de forma analítica: t = (1/k) · ln[(T₀ − T_amb) / (T_m − T_amb)], y sirve como valor de referencia para comparar el error de cada método numérico.

Nota: este es un modelo educativo simplificado (k constante) para comparar métodos numéricos de resolución de EDOs. La estimación forense real utiliza modelos más completos (p. ej. nomograma de Henssge) y no debe emplearse como evidencia pericial.
